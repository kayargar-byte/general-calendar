# 設計摘要：一戶通智能日曆

澳門創新比賽項目。面向一般澳門居民的 Web 日曆，結合一戶通個人資料（證件到期日）、AI 讀文檔自動建事件、AI 即時搜尋生成日曆內容。

## 已定決策

| # | 決策 | 出處 |
|---|---|---|
| 1 | 政府資料混合路線：證件到期日走一戶通 OAuth API，津貼到期日手動輸入＋OCR；demo 用模擬數據 | ADR 0001 |
| 2 | Web 優先，日後可遷移手機 app | ADR 0002 |
| 3 | 自建日曆，不同步 Google／Apple | ADR 0003 |
| 4 | 事件存 localStorage、原檔存 IndexedDB、金鑰與 AI 處理放薄後端 | ADR 0004 |
| 5 | 文檔事件全自動寫入，來源可追溯＋一鍵復原，無確認步驟 | ADR 0005 |

## 產品規格

- **用戶**：一般澳門居民；介面繁體中文
- **文檔輸入**：Word／PDF／Excel／圖片／截圖；Excel 視為批量事件表，其餘抽出「日期＋事件描述」配對（中英葡 OCR）
- **AI 搜尋**：任意主題即時搜尋；有日期錨點的結果自動入日曆（帶來源 URL），無日期的回覆「找不到可排程內容」
- **提醒**：瀏覽器通知；證件提前 90／30／7 天，津貼提前 7 天，一般事件前一天
- **互動**：hover／長按 → 原文高光段落浮窗；輕擊 → app 內檢視完整原檔或開網站
- **demo 主秀**：文檔 → 日曆（主），AI 搜尋與到期提醒（輔）

## 待定項目

- 技術棧（建議組合：Next.js ＋ Vercel Functions ＋ OpenAI API ＋ pdf.js／mammoth／SheetJS，待確認）
- 產品名稱
- 一戶通 client_id 申請資格（學生隊伍可否申請，需聯絡行政公職局 8866 8866，需驗證）

## 風險與對策

- **AI 抽錯日期**：全自動寫入靠「來源可追溯＋一鍵復原」兜底
- **一戶通 3.0 已宣布 AI 主動服務**：pitch 需準備差異化——本產品是第三方、跨資料來源、用戶自主控制
- **《個人資料保護法》**：demo 全程使用模擬數據；正式上線需用戶明確同意
- **OCR 品質**：澳門文檔中葡雙語，多模態 LLM 直接讀原檔可繞過傳統 OCR 的語言瓶頸（技術棧待定時留意）
