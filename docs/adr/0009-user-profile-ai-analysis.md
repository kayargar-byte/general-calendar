# 0009：用戶畫像驅動 AI 分類與推薦

AI 搜索要「按日曆分類歸類」且「依用戶特徵即時分析」。既有 prompt 已列出分類清單但歸類弱（無效 ID 靜默回落 personal），且全案無任何用戶畫像概念。本決策引入畫像資料層：從本地行為與手動偏好聚合摘要，注入搜索與文檔抽取的 prompt，驅動分類偏置、澄清選項個性化與主動推薦。

## 決策

- **資料源四項**：事件歷史＋分類使用頻率、文檔匯入類型、搜索行為（查詢與採納，50 筆 FIFO）、手動偏好（優先分類、興趣主題、身份資訊）。
- **聚合在本地、即時重算**：`buildProfile` 為純讀函數，每次 AI 請求重新聚合 localStorage／IndexedDB 元數據，無快取——「實時」即「每次請求反映最新」。
- **只送聚合摘要**：注入 prompt 的是 `profileToText` 的統計摘要，不含事件標題、文檔名稱或原文；空畫像不注入整段（避免無資料仍加偏置）。
- **搜索路徑注入**：`askAi`（search:true）把畫像摘要寫進 system prompt；`search:false` 純解析路徑保持向後相容，不帶畫像。
- **文檔抽取路徑注入**：瀏覽器匯入經 multipart `profile` 欄位直送；server 存記憶體 `lastProfile` 快取，桌面右鍵匯入（X-Stash 不帶 profile）沿用。此為 ADR 0004 薄後端與 ADR 0008 記憶體收件箱例外的延續。
- **主動推薦**：模型在 events 回應回傳 `recommendations`（topic＋reason），面板渲染 chips，點擊即以該主題追問。

## 後果與風險

- **聚合資料仍外送第三方**：即便只送聚合摘要，畫像內容仍經代理轉發給外部模型——ADR 0004「敏感資料不出裝置」是程度而非絕對；正式上線需用戶同意。
- **「可靠歸類」是 LLM 行為**：prompt 強化（分類定義＋規則）與畫像偏置不保證 100%；無效分類仍回落 personal（既有行為）。
- **server 快取為記憶體態**：重啟即清；瀏覽器未推過畫像時桌面匯入無畫像（優雅降級，prompt 省略畫像段）。
- **畫像只送聚合、不送原始內容**：模型無法引用具體事件，分類偏置依賴統計信號，細粒度精準度有限。

## Considered Options

- **手動偏好 vs 純行為推導**：用戶確認兩者併存；身份欄位較敏感，僅以聚合值進 prompt，不另建高敏儲存。
- **server 持畫像 vs 前端聚合**：server 持畫像需把事件資料送 server，違反 ADR 0004；選前端聚合、只送摘要。
- **每請求重算 vs 快照快取**：資料量小（localStorage），重算零成本、天然即時；無需快照同步。
- **`recommendations` 併入 events 回應 vs 新回應型別**：併入 events 少一條路由分支，與既有判別式協定相容。
